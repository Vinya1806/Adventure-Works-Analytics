# Adventure Works Analytics Project

## Overview
This project analyzes Adventure Works sales data using Excel, SQL, Power BI, and Tableau.

## Tools Used
- Excel
- SQL
- Power BI
- Tableau

## Key Insights
- Q4 has highest sales
- Bikes category gives maximum revenue
- USA and Australia lead in sales

## Files Included
- Adventure Works PPT
- Power BI Dashboard
- Tableau Dashboard
- SQL Queries

## Conclusion
This project demonstrates end-to-end data analytics and dashboard creation.
